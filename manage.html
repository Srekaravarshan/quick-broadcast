How to export contacts from a phone
  • Android: contacts usually sync to Google. contacts.google.com → Export → Google CSV.
  • iPhone: icloud.com/contacts (or the Mac Contacts app) → select all → Export vCard.
  • Excel: File → Save As → CSV. Needs a phone column; a name column is optional.
