Import contacts

Pick or drop a .csv (Google Contacts export, Excel “Save as CSV”, any sheet with a phone column) or a .vcf (iPhone / Mac Contacts export). The file is read only in this browser and isn’t uploaded anywhere.

You can edit or delete lines above before adding them. Numbers without a country code get added.

How to export contacts from a phone
  • Android: contacts usually sync to Google. Open contacts.google.com → Export → Google CSV.
  • iPhone: on a Mac, Contacts app → select all → File → Export → Export vCard. Or on icloud.com/contacts → select all → Export vCard.
  • Excel: File → Save As → CSV (Comma delimited). Needs a column with the phone numbers; a name column is optional.
